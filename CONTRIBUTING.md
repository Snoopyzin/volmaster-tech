# Contribuindo para Volmaster Tech

Obrigado por considerar contribuir para o projeto Volmaster Tech! 🎉

## Como Contribuir

### Reportando Bugs
- Use a aba "Issues" no GitHub
- Descreva o bug detalhadamente
- Inclua screenshots se possível
- Informe navegador e versão

### Sugerindo Melhorias
- Abra uma issue com a tag "enhancement"
- Explique claramente a melhoria proposta
- Descreva os benefícios

### Pull Requests
1. Fork o projeto
2. Crie uma branch para sua feature (`git checkout -b feature/NovaFeature`)
3. Commit suas mudanças (`git commit -m 'Adiciona nova feature'`)
4. Push para a branch (`git push origin feature/NovaFeature`)
5. Abra um Pull Request

## Padrões de Código

### HTML
- Use indentação de 4 espaços
- Sempre inclua atributos `alt` em imagens
- Use tags semânticas quando possível

### CSS
- Organize por seções
- Use comentários para separar seções
- Prefira classes reutilizáveis

### JavaScript
- Use ES6+ quando possível
- Comente código complexo
- Mantenha funções pequenas e focadas

## Processo de Review
- Todo PR será revisado antes do merge
- Feedback será dado em até 48 horas
- Mudanças podem ser solicitadas

## Código de Conduta
- Seja respeitoso e profissional
- Aceite feedback construtivo
- Foque na qualidade do código
