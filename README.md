## 📋 Descrição

Volmaster Tech é um website moderno e interativo apresentando **cursos de treinamento e capacitação** para manutenção e diagnóstico de caminhões. O projeto inclui uma página inicial com carousel de **9 cursos**, catálogo completo e página de contatos totalmente funcional.

## 📱 Responsividade

O projeto possui breakpoints em 3 principais resoluções:

- **Desktop**: Full width (acima de 768px)
- **Tablet**: Otimizado (entre 480px e 768px)
  - Dots com max-width: 400px
  - Grid produtos: 2 colunas
  - Layout formulário: 1 coluna
  
- **Mobile**: Comprimido (abaixo de 480px)
  - Dots com max-width: 280px
  - Grid produtos: 1 coluna
  - Navegação ajustada
  - Números do slide menores

## 🚀 Quick Start

### 📥 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/volmaster-tech.git

# Entre na pasta do projeto
cd volmaster-tech

# Abra no navegador
# Opção 1: Abrir diretamente o arquivo index.html
# Opção 2: Usar Live Server (VS Code extension)
# Opção 3: Usar servidor local (veja abaixo)
```

### 🖥️ Executar Localmente

**Opção 1: Abrir arquivo local (desenvolvimento)**
1. Navegue até a pasta do projeto
2. Clique duplo em [index.html](index.html) para abrir no navegador
3. Use a navegação do menu para acessar outras páginas

**Opção 2: Usar um servidor local (recomendado)**
```bash
# Python 3
python -m http.server 8000

# Node.js (com http-server instalado)
npx http-server

# PHP
php -S localhost:8000
```
Depois acesse: `http://localhost:8000/`

**Opção 3: VS Code Live Server**
1. Instale a extensão "Live Server" no VS Code
2. Clique com botão direito em [index.html](index.html)
3. Selecione "Open with Live Server"
